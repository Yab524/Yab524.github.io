HOW TO VIEW
1. Unzip this folder.
2. Keep index.html, style.css, and the assets folder together.
3. Double-click index.html to open the portfolio in your browser.

HOW TO PUBLISH FREE WITH GITHUB PAGES
1. Create a public GitHub repository named yeabsra-project-management-portfolio.
2. Upload index.html, style.css, and the entire assets folder.
3. Go to Settings > Pages.
4. Choose Deploy from a branch, then main and /(root).
5. Save. GitHub will create your live URL.

Note: Some included files are named as course exemplars/templates. The website presents them as course-based practice artifacts, not paid client work.
